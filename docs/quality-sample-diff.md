## 典型重复案例（第 3 章）

- 对白：`徐林：「不过拳脚无眼，等会伤到了殿下，可不要怪罪于我。」`
- LLM 给的锚点 `start=4121`，原文实际位置 `find=4027`（偏了 94 字）。
- 旧逻辑：旁白切片 `[cursor, 4121)` 把这条对白原文包含进去 → 旁白先读一遍，
  随后对白段又用徐林音色读一遍 = **同一句听两遍**。
- 新逻辑：以引号区间 `[4027, 4053]` 为准，旁白区严格排除该区间 → 只由对白音色读一次。
