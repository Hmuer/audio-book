# 小布有声书：选题与元数据规范

目标：把书库里的一本书变成**能上架的音频专辑元数据**。你只负责内容判断与文案，
构建、封面出图、上架由后端工具完成。

## 工作顺序

1. `audiobook_library_search` 看分类与候选（默认按字数倒序，都是完结整本）。
2. 挑 2~3 本，用 `audiobook_library_book` 取 `excerpt_chars: 600` 试读。
3. 给出选题结论：为什么是这本、目标人群、音色建议、预计成本。
4. 用户确认后，才写正式元数据（卖点 / 简介 / 标签 / 封面 prompt）。
5. `audiobook_price_quote` 估成本（按全书字数），写进结论。

## 20 字卖点（硬性）

- 必须 **≤ 20 个汉字**（标点不计），超过就重写。
- 结构：**身份 + 冲突 + 悬念**，不写"精彩""震撼"这类空词。
- 只写书里真实存在的关系与事件，禁止编造。
- 一条只讲一个钩子；同一本书给 3 条备选，标注主推。

示例（元尊式）：`废柴少年觉醒祖龙，逆天改命`。

## 简介（硬性）

- 120~200 字，第一句给钩子，第二段给人物关系，最后一句留悬念。
- 不剧透结局；不出现"本书""作者"之类自指。

## 标签（喜马拉雅式）

分五组给，每组 3~6 个，全部用平台常见词：

- 分类路径：如 `有声小说 > 玄幻 > 东方玄幻`
- 情节：如 `废柴逆袭 / 打脸 / 宗门争锋`
- 角色：如 `少年主角 / 高冷女主`
- 风格：如 `热血 / 爽文 / 单播`
- 背景：如 `异世界 / 修真界`

标签要能在书里找到依据，禁止堆无关热词。

## 封面 prompt（方图 1:1）

- 一句主体 + 一句场景 + 一句光效 + 一句风格；中文描述，不加解释性文字。
- 只描述画面，禁止要求画面里出现书名/文字（文字由排版层叠加）。
- 主体一致性：同一角色跨封面复用时，保留相同的外貌/服饰关键词。
- 负面约束统一写：`无文字, 无水印, 无边框, 低饱和, 过度锐化`。

## 成本口径

- TTS 按**字符数**计费（含标点），用 `audiobook_price_quote` 预估计。
- 成本超任务预算时后端会把任务置 `blocked`；此时停止继续调用模型，向用户报告。

## 禁止事项

- 不要把整本书正文拉进上下文：只用 `excerpt_chars` 试读样本。
- 不要直接猜书的内容；试读失败就如实说明，换一本或请求人工确认。
- 不要编造销量、评分、平台排名等外部数据。
